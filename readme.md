# Mohamed Azelmad Portfolio

A professional, multilingual portfolio for Mohamed Azelmad, a Full-Stack and FinTech developer based in Morocco.

The website presents my experience, technical skills, academic background, certifications, selected projects, and contact information. It is available in English, French, and Arabic and includes light and dark themes.

## Overview

This portfolio highlights work across software engineering, financial technology, artificial intelligence, digital governance, mobile development, and telecommunications. The interface is designed to be responsive, accessible, and easy to navigate across desktop and mobile devices.

- Trilingual interface: English, French, and Arabic

## Getting Started

### Prerequisites

No external package manager or build tool is required. A modern browser is sufficient.

### Run Locally

1. Clone the repository:

```bash
git clone https://github.com/azelmad2004/portfolio.git
```

2. Open the project directory.

3. Open `index.html` directly in your browser, or serve the directory with a local static server:

```bash
python -m http.server 8000
```

4. Visit `http://localhost:8000`.

## Customization

- Update portfolio content in `index.html`
- Modify translations and interactive behavior in `app.js`
- Change the visual design in `style.css`
- Replace images and documents in `assets/` and `pdfs/`
- Update external profile and project links in `index.html`

## Deployment

The website can be deployed to GitHub Pages, Netlify, Vercel, or another static hosting platform.

For GitHub Pages:

1. Push the project to a GitHub repository.
2. Open repository Settings.
3. Select Pages.
4. Choose the deployment branch and root directory.
5. Save the configuration and wait for deployment.
